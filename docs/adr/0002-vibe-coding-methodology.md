# ADR 0002: Development Methodology and Repository Purpose

* **Status:** Accepted
* **Date:** 2026-07-31

## Context

The project aims to study and understand in detail the core concepts involved in building and training Large Language Models (LLMs) end-to-end from scratch, based on the Stanford CS336 course.

## Decision

1. **Primary Purpose:**
   - Establish a solid conceptual and practical foundation aimed at full implementation of an LLM training pipeline in the future.

2. **Development Methodology (*Vibe Coding* + Explanatory Learning):**
   - Tasks and components will be developed using *vibe coding* (AI-assisted development).
   - All architectural decisions, algorithms, and implementations must be accompanied by detailed documentation and clear conceptual explanations, enabling deep understanding and replication across different contexts.

## Consequences

- Accelerated learning through AI assistance without sacrificing conceptual depth.
- Repository serves as a reusable educational and practical guide for future LLM projects.
